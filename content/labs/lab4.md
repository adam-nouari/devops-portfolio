# Lab 4 - Version Control, Build Systems et Tests

## Objectifs
Maîtriser le contrôle de version, les systèmes de build et les tests automatisés.

## Partie 1 : Version Control avec Git
Gestion des branches, pull requests, résolution de conflits et bonnes pratiques Git en équipe.

## Partie 2 : Build Systems
Automatisation du build avec npm/Node.js. Configuration des scripts de build pour le frontend React et le backend Express.

## Partie 3 : Tests Automatisés
Écriture de tests unitaires et d'intégration avec Jest et Supertest. Tests de l'API REST du backend Task Manager.
